89 /*
90 Vector registers with the same index number share their storage. e.g. zmm6, ymm6, and xmm6
91 GPRs with the same index number share their storage. e.g. rcx and ecx
92
93 For example, writing data to zmm6 overwrites the data stored in xmm6.
94 When context-switching a fiber, all non-volatile registers have to be preserved throughout the context-switches.
95
96 [FROGMAN ENGINE AMD64 ABI SPECIFICATION]
97 Unlike the Windows x64 ABI which treats the upper bits of vector registers as volatile
98 the Frogman Engine AMD64 ABI explicitly preserves the full widths of SIMD registers 6 through 15.
99 Depending on FE::SIMD_auto_alignment::size, this guarantees the preservation of full
100 YMM (256-bit) or ZMM (512-bit) state across fiber context switches, allowing safe yields
101 during heavy vectorized workloads.
102 */
